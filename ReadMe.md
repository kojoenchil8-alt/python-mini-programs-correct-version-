# Python Mini-Programs: Rock, Paper, Scissors & Password Generator
A Collection of two begineer-friendly programs built for the fun of the game

## Programs that i have are

### 1. Rock Paper Scissors ('rock paper scissors.py')
A classic game where a player competes against a computer
it randomly picks the computer's move using Python's random module
it checks win loss and ties  conditions for every round
but if u put any other thing than rock paper scissors it will ask u to chose again

### 2. Random Password Generator ('random password generator.py')
it is a tool that generates random passwords based on your prefrence
 it lets the user choose how long they want their password to be
it builds a randomized password using letters numbers, symbols

### 3. Main Launcher ('Main.py')
-A menu-driven script that lets players choose and run any mini-program from one place

## How to run
1. Make sure Python 3 is installed on your computer
2. Open a terminal inside the project folder
3. Run 'python' rock paper scissors.py to play rock paper scissors  or 'python rnadom password generator.py to generate a password
